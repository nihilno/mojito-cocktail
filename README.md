# 🍹 Lazy Lagoon — GSAP Animation Playground

A React + TypeScript bar-themed web app built as a creative playground to explore **GSAP animations**.  
This project experiments with advanced animation techniques, responsive layouts, and smooth video integration to deliver a visually engaging experience.

---

## ✨ Features

- **GSAP Core Methods**:
  - **to**, **from**, and **fromTo** for precise animation control
- **GSAP Plugins**:
  - **SplitText** for dynamic text reveals
  - **ScrollTrigger** for scroll-driven animations and hero section effects
- **Hero Video Integration**:
  - Enhanced with **FFmpeg** for optimized playback
  - Smooth scroll-sync effect for immersive storytelling
- **Responsive Design**:
  - Powered by **react-responsive** for adaptive layouts
  - Works seamlessly across desktop, tablet, and mobile
- **TypeScript Support**:
  - Strong typing for safer, more maintainable code
- **Modern UI**:
  - Clean, playful bar-inspired visuals with fluid transitions

---

## 🛠️ Tech Stack

- React — Component-based UI
- TypeScript — Static typing and maintainability
- GSAP — Animation engine
- react-responsive — Media query handling
- FFmpeg — Video optimization
- CSS/Tailwind — Styling and responsiveness
